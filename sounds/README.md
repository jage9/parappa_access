# Sounds

Parappa Access includes seven replaceable WAV sounds:

| File | Sound |
| --- | --- |
| triangle.wav | Triangle (I) |
| square.wav | Square (J) |
| x.wav | X (K) |
| circle.wav | Circle (L) |
| l1.wav | L1 (Q) |
| r1.wav | R1 (E) |
| handoff.wav | Teacher-to-player handoff |

Use Learn sounds to hear them. Arrows select a sound; Enter plays it.
The six button keys also play their sounds directly.

To replace a sound, use the same filename and restart Parappa Access.
Files must be uncompressed PCM WAV, 16-bit or 24-bit, mono or stereo,
8?192 kHz. There is no duration limit.

Cue volume, panning and the handoff sound can be adjusted in Settings.
The handoff sound stays centered. Your files are never rewritten during play.
